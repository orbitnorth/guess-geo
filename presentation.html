5-Round Match Flow & Interactive Guessing

🌍 5-Round Solo Exploration

Each game challenges the explorer across 5 distinct satellite mystery destinations worldwide:

  • 1 Mystery Location: High-res photo loads with lightbox zoom for architectural, terrain, and road clues.
  • 2 Active 3D Exploration: Spin, tilt, and zoom the 3D globe to pinpoint the exact location on Earth.
  • 3 Pin Lock-in: Confirm your guess flag; timer freezes and controls lock to prevent accidental movement.
  • 4 Cinematic Reveal: Camera swoops dynamically to the actual location, vaulting a 3D distance arc.
  • 5 Evaluation & Recap: Distance calculation in km, animated score count-up, and final match report.

⚔️ Real-Time Combat & Health Rules

Two explorers clash head-to-head on identical mystery locations. Proximity dictates survival:

  • ✔ Distance Delta Damage: Whichever player is further takes damage equal to the difference in kilometers: |DistP1 − DistP2| × Multiplier.

🎮 Three.js Rendering Configuration

The renderer is configured for maximum visual fidelity and optimal GPU resource management:

  • ✔ ACES Filmic Tone Mapping: Simulates high dynamic range (HDR) film response to avoid blown-out highlights.
  • ✔ Clamped DPR: `Math.min(devicePixelRatio, 2)` prevents 3x/4x mobile screens from dropping frames.
  • ✔ SRGB Color Space: Ensures texture colors render true-to-life without gamma degradation.
// Three.js WebGLRenderer Setup this.renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true, powerPreference: 'high-performance', }) this.renderer.setPixelRatio( Math.min(window.devicePixelRatio || 1, 2) ) this.renderer.outputColorSpace = THREE.SRGBColorSpace this.renderer.toneMapping = THREE.ACESFilmicToneMapping this.renderer.toneMappingExposure = 1.18

Part 2 Member 2 • Custom GLSL Shaders

Atmospheric Glow via Custom GLSL Rim Shader

✨ Fresnel Rim Physics

An inverted outer sphere (scale 1.14x) uses a custom GLSL shader that calculates the angle between vertex normals and the camera view vector:

  • ✔ `THREE.BackSide`: Renders only the outer rim shell without obscuring continental maps.
  • ✔ Additive Blending: Glow smoothly layers over the sky background.
  • ✔ Exponential Falloff: Soft $(0.62 - \mathbf{n} \cdot \mathbf{v})^{3.2}$ creates a realistic planetary atmosphere.
// GLSL Fragment Shader uniform vec3 glowColor; uniform float intensity; varying vec3 vNormal; void main() { // Dot product between normal and camera gaze float rim = pow( 0.62 - dot(vNormal, vec3(0.0, 0.0, 1.0)), 3.2 ); gl_FragColor = vec4(glowColor, 1.0) * clamp(rim * intensity, 0.0, 1.0); }

Part 3 Member 3 • Spherical Mathematics

Converting Latitude & Longitude to 3D Cartesian Space

📐 Spherical Coordinate Transformation

Spherical trigonometry translates polar angle $\phi$ (latitude) and azimuthal angle $\theta$ (longitude) to 3D $(x, y, z)$ on the globe:

export function latLonToVector3(lat, lon, radius) { const phi = THREE.MathUtils.degToRad(90 - lat) const theta = THREE.MathUtils.degToRad(lon + 180) return new THREE.Vector3( -radius * Math.sin(phi) * Math.cos(theta), radius * Math.cos(phi), radius * Math.sin(phi) * Math.sin(theta) ) }

🧭 Inverse Vector3 to Lat/Lon

When the user clicks the 3D globe, the inverse function extracts real-world geographical coordinates:

const lat = 90 - radToDeg(Math.acos(p.y)) let lon = radToDeg(Math.atan2(p.z, -p.x)) - 180 if (lon < -180) lon += 360
  • ✔ Continuous wrap-around handling at meridian boundaries.
  • ✔ Precision within 0.001 degrees of true geographic position.
Part 3 Member 3 • Geodesic Physics

Great-Circle Haversine Formula & Scoring Curve

📏 Great-Circle Haversine Equation

Computes shortest surface distance over the Earth ($R = 6,371\text{ km}$):

a = sin²(Δlat/2) + cos(lat₁) × cos(lat₂) × sin²(Δlon/2) distance = 2 × R × arcsin(√a)

Accurate across the International Date Line and Polar regions, avoiding Mercator projection distortions.

🎯 Exponential Score Falloff Curve

Score decays non-linearly with distance to reward razor-sharp precision:

  • ✔ < 2,000 km: 2,000 – 3,500 Points (Decent guess)

Real-Time Procedural Cloth Wave Animation

🚩

Dynamic Vertex Mesh Displacement

Every frame of the requestAnimationFrame loop, each vertex of the 12×5 subdivided cloth mesh is displaced dynamically along the Z-axis using traveling sine waves:

function waveFlag(flag, time) { const pos = flag.userData.cloth.geometry.attributes.position for (let i = 0; i < pos.count; i++) { const x = pos.getX(i) // Propagating wave: amplitude scales with distance from pole (x / FLAG_W) const z = Math.sin(x * 11 - time * 5.5) * 0.05 * (x / FLAG_W) pos.setZ(i, z) } pos.needsUpdate = true geometry.computeVertexNormals() }
