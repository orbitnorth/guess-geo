Project Structure & Full-Stack Engine

🏗️ Framework & Backend

  • ✔ Next.js 16 (Turbopack): Hybrid App Router supporting both high-speed client-side 3D canvasing and server-side API routes.
  • ✔ Serverless SQLite & Drizzle: Zero-dependency database with auto-initialization (`initDb()`) in `/tmp` for serverless environments.
  • ✔ JWT & Auth Pipeline: Secure stateless sessions (`jose` HS256) storing explorer profiles and custom avatars.

📁 Component Decoupling

  • ✔ `GlobeEngine.js`: 100% pure Three.js imperative rendering engine. Completely isolated from React re-renders.
  • ✔ `GeoGuessGame.jsx`: State controller coordinating the round deck, timer, score calculation, and duel mechanics.
  • ✔ UI Modals & HUD: Lightweight overlay components (`DuelHud`, `Modal`, `RegisterModal`).

1v1 Duel Arena & Room Synchronization

⚔️ 5,000 HP Clash Mechanics

Each player starts with 5,000 HP. Distance difference between guesses translates directly to damage against the further player.

  • ✔ 15-Second Rounds: High-paced countdown timer with auto-lock on expiration.

Initialized with ACES Filmic tone mapping and device pixel ratio capping for smooth 60 FPS mobile and desktop performance.

🕹️ OrbitControls with Inertial Damping

  • ✔ Smooth Damping: `dampingFactor = 0.07` produces an organic, heavy rotational feel.
  • ✔ Polar Clamping: Prevents gimbal flipping by locking vertical angles between `0.15` and `π - 0.15`.
  • ✔ Idle Auto-Rotate: Seamless `0.35` speed drift that smoothly disengages on user touch or drag.

Spherical Coordinates & Haversine Distance

📐 Equirectangular to 3D Cartesian

Translates geographic latitude ($-90^\circ$ to $+90^\circ$) and longitude ($-180^\circ$ to $+180^\circ$) into 3D Cartesian coordinates on the sphere:

const phi = THREE.MathUtils.degToRad(90 - lat) const theta = THREE.MathUtils.degToRad(lon + 180) return new THREE.Vector3( -radius * Math.sin(phi) * Math.cos(theta), radius * Math.cos(phi), radius * Math.sin(phi) * Math.sin(theta) )

📏 Great-Circle Haversine Formula

Calculates exact planetary surface distance in kilometers:

a = sin²(Δlat/2) + cos(lat₁) × cos(lat₂) × sin²(Δlon/2) distance = 2 × 6371 × asin(sqrt(a))
  • ✔ Drives score calculation (0 to 5,000 pts).
  • ✔ Calculates 1v1 battle HP damage penalties.
